POKÉMON POSTERS

abrir no behance

design editorial - 2026

Este projeto é um exercício de estudo e experimentação em design gráfico, desenvolvido a partir do universo Pokémon para explorar diferentes possibilidades de composição visual.
O objetivo foi experimentar combinações de cores, tipografias, texturas e elementos gráficos, criando diferentes abordagens visuais para cada poster. Busquei trabalhar cada composição de forma individual, explorando estilos e recursos que valorizassem as características e a identidade de cada personagem.
O projeto também foi uma oportunidade para experimentar novas soluções visuais e desenvolver uma coleção coesa, mas com personalidade e características próprias em cada peça.

*projeto pessoal realizado para estudos e aprimoramento de habilidades
